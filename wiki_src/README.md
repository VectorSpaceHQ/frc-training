Zim Wiki
--------
The contents of this Wiki are produced as a [Zim Desktop Wiki](https://zim-wiki.org/).  

Setup
-----

### Install Zim
Follow the instructions on the [Zim Download](https://zim-wiki.org/downloads.html) page to install for your Linux distro.  For Windows and Mac, following the instructions to download and install.
When you first open Zim, it will ask you to create your own personal notebook.  Follow the prompts to create your personal notebook.

### Import this Wiki

1. Open Zim
2. Select `File -> Open Another Notebook`
3. In the `Open Network` dialog box, click the `Add` button.
4. Browse to the location of this Wiki
	1. Name: `Wiki`
	2. Folder: `~/git/frc-example/wiki_src` (Example, your path may be different).
5. After importing, open the Wiki.


### Enable Plugins
This wiki uses a couple of additional plugins.

1. In Zim, select `Edit -> Preferences`.
2. In the `Preferences` dialog, select the `Plugins` tab.
3. Check the boxes for the following plugins:
	1. `Source View`
	2. `Table of Contents`
