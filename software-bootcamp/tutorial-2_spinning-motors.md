# Software Bootcamp Tutorial 2
## Spinning Motors
Created Wednesday 12 August 2026


Steps
=====
Shooter/Flywheel Simulation 
----------------
Follow the [YAMS shooter/flywheel tutorial](https://yagsl.gitbook.io/yams/documentation/tutorials/shooter-flywheels).

This tutorial was written to be used with Sparkmax motors; however, we'll be using TalonFX Kraken motors. Modify as needed using the [Phoenix 6 API Reference](https://v6.docs.ctr-electronics.com/en/stable/docs/api-reference/index.html) and the [completed version](https://github.com/VectorSpaceHQ/frc-training/tree/main/software-bootcamp/YamsArmExample/src/main/java/frc/robot).


Real World
----------------
Once you've finished the YAMS tutorial and have the flywheel spinning in simulation, deploy to woodbot.

Arm Simulation
--------------
Next create a new project and follow the [YAMS Arm tutorial](https://yagsl.gitbook.io/yams/documentation/tutorials/arm).
